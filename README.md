# Timezone & Date Format

Плагин Obsidian (только десктоп): рабочий часовой пояс и формат «системных» дат.

## Пояс

Плагин подменяет часовой пояс окна через Chrome DevTools Protocol (`Emulation.setTimezoneOverride` на `webContents.debugger`). Всё, что считает местное время внутри окна, переходит на выбранный пояс: Bases (`file.ctime`, `now()`, `today()`), Tasks, ежедневные заметки, шаблоны, Templater, Dataview. Всплывающие окна работают в том же процессе и получают пояс сами. Время файлов на диске не меняется, меняется только то, как его читают.

- Выбор: команда **Choose working timezone** или клик по поясу в строке состояния. Последние выбранные пояса стоят в начале списка.
- **Use system timezone** снимает подмену.
- CLI Obsidian работает через тот же отладчик. `obsidian dev:debug off` отключает его, и подмена сбрасывается; плагин сам подключается заново и возвращает пояс.
- После переключения перерисовываются вкладки Bases и заметки. У заметок в режиме редактирования при этом теряется история отмены.

## Формат дат

Bases рисует даты через moment: `L` для даты и `L LT` для даты со временем. Плагин переопределяет эти два токена в текущей локали moment (`moment.updateLocale`) и при выключении возвращает исходные. Пустое поле означает формат локали по умолчанию (для en-gb это `DD/MM/YYYY` и `HH:mm`).

Поля дат в Properties рисует сам Chromium по региональному формату macOS (System Settings → General → Language & Region), moment их не трогает.

## Установка

```
./install.sh            # копирует в ~/КэАли/.obsidian/plugins/tz-format и перезагружает плагин
./install.sh ~/другое   # в другое хранилище
```
